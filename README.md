# blog

个人博客（基于 Markdown，**可能做成静态部署**）。

> 项目名占位：域名/主题定了再改目录名。

## 空间规划

| 目录 | 用途 | 状态 |
|---|---|---|
| `posts/` | **blog 文章** .md 源文件（内容层，框架无关） | 已启用 |
| `docs/` | 项目相关文档：构建/部署方案、定制记录 | 已启用 |
| `public/`、`src/`、构建配置 | 静态生成器落地（Astro/Hugo/…，选型后建） | 预留 |
