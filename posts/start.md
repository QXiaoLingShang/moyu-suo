## 引子

不知道为什么，我很久以前就想要一个属于自己的博客了。


- 也许是因为博客是那些大佬的普遍一个特征？（至少我阅读过的很多博客，对我都有很大的启发)
- 也许是自己设计一个博客本身很酷？<span class="spoiler">（~~虽然目前这个博客是纯粹的模板~~）</span>
- 也许是我有很多东西没地方说？<span class="spoiler">（i人别指望了）</span> 

但不管怎么样，我总是有种莫名的渴望，就是想要这么一个专属于自己的博客，记录各种有的没的。
## 拖延症？焦虑？

虽然这个想法我很久就有了。。。
但显然，我迟迟没有付诸于行动。。。。。一直到现在。。。

我觉得我有必要复盘一下了：
1. 首先最明显的原因，肯定是我**懒癌**发作了<span class="spoiler">~~（真的不是我懒，是我身体不想动）~~</span>
以前一了解什么服务器啊，什么域名啊，什么图床[^1]啊，感觉一堆配置好麻烦。
后来学了点前端，感觉写个 UI/UX 非常细节的 blog 前端更麻烦。。。
后来学了点后端，感觉写一个高性能，高并发，高可用的 blog 后端更加麻烦。。。
久而久之就搁置了。。。X_x

2. 当然。。。仔细想想。。。什么懒啊，不想做啊，这都是**借口**。
我都**有空捣鼓其他**各种有的没的东西了（而不是成天刷视频），怎么可能**没时间去捣鼓博客**呢？
真要扒开我这一层的虚伪。。。那只可能是 **焦虑/害怕** 了。

我焦虑我维护不好这么一个博客，
我害怕我没有能力产出好的文章
我甚至害怕我 TM 部署完后我写不了几个字。就草草吃灰了。
（人太 i 了，感觉总想写点什么，又感觉什么也写不出来，所以焦虑）

> PS：再深究的话。。。就是性格缺陷了
> 
> 导致我错过了很多东西，算了，这些等以后再来自责吧。

## 为什么又突然有了呢？

嘛，突然想不开了想找点罪受呗，这不很显然的事？:D

或者说，我突然想通了。反正大不了就社死。 <span class="spoiler">（感觉除了我以外的 99% 的 i人都不是真正的 i 人）</span> 

~~多大点事嘛。（笑）~~

其实我想通了，以前因为没钱搞供着服务器和域名（借口），之后是因为写不出东西（虽然这个是根本原因），在之后是因为写不出好看的博客网址（换了个借口）

总之就是我总是给我找各种借口去掩盖我害怕我写不出东西，我这么生涩、枯竭的词汇写不出什么话来。

所以一切的一切这些积累起来，就突然就在今天这一刻，不知道为啥的爆发了。就想要突破自我了，想要改变现状了<span class="spoiler">（真的吗？）</span> 就下定决心来写一篇来开个头（毕竟万事开头难嘛）


<i>松了一口气</i>

## 羞耻的聊完了，聊聊这个博客本身吧

这个博客是基于 Astro[^2] 构建的，套了个现成的 AstroPaper 模板。所有配置都是 deepseek flash + pi[^3] 配的（deepseek 神力！不用我自己去捣鼓了）。

目前对模板主题的更改很少，就加了个 <span class="spoiler">(这个从萌娘百科里“借鉴”而来的)</span> 这玩意。

目前这个 blog 的用途可能会用来记录一些我在 github 上一直是 private 状态的笔记？<span class="spoiler">（当然肯定不包括以前的，以前的笔记特别不完善，纯粹只能给我自己看，我又懒得去维护）</span> 或者一些使用体会？一些碎碎念？一些资料分享？

反正大概率没人看的，就权当我自娱自乐吧~

[^1]: 图床：专门存放图片的在线服务，给文章配图当外链仓库用。

[^2]: Astro：一个静态网站生成器（写 markdown 就能生成整站）；AstroPaper 是它的开源博客主题，开箱即用，我现在用的模板就是它。

[^3]: pi 可以简单理解成 codex cli / opencode / Claude Code 这类终端里的 harness（也有人叫 agent；“harness”这词不知道谁先提出来的，反正大家都这么叫了）。pi 本体非常极简，对应 Unix 的 worse is better 哲学；但它又扩展出很多插件（类似 dsh 那种），能相对个性化一点。
