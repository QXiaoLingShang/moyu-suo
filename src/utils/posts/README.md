# 文章集合与地址

页面、RSS 和文章卡片共用这里的文章处理逻辑。输入来自 Astro 内容集合；作者正文、标题、标签和发布时间继续以 `posts/` 为准。

| 文件                | 职责                                                                           |
| ------------------- | ------------------------------------------------------------------------------ |
| `postFilter.ts`     | 草稿、测试标签和定时发布的可见性规则；默认排除测试文章，由明确的消费方选择包含 |
| `getSortedPosts.ts` | 先筛选，再按修改时间或发布时间降序排列                                         |
| `getUniqueTags.ts`  | 从符合筛选规则的文章提取标签，保留标签原名与 slug 的区分                       |
| `getPostPaths.ts`   | 文章静态路径和可访问 URL，沿用内容目录、slug、部署 base 与语言路由             |

这些函数供内容生成和页面组合使用；筛选依赖当前时间、配置和开发模式，不把它们视作不受运行环境影响的纯函数。通用 slug 转换仍在父目录的 `slugify.ts`，不让全站导航或过渡名称反向依赖文章集合。

回归检查文章与标签列表、文章详情、归档、RSS 以及搜索构建的选择范围；测试文章能直达和出现在测试标签目录，不代表应进入默认文章列表或搜索索引。文章写作约定见 [posts/_README.md](../../../posts/_README.md)。
