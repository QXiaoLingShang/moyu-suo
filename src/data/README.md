# 首页入口

在 `homeEntrances.ts` 中按阅读顺序添加、删除或调整入口。相邻两项占一行，第一项在左、第二项在右。首页不维护单独的定位表；桌面圆周端点、连接线和入口位置会根据可见数量重新计算。

- `id`：稳定的唯一标识。
- `title`、`description`：中英文标题和共用说明区的文案。
- `route`：站内路径，不含语言和部署基础路径；页面负责补齐。开放入口需要提供此项。
- `visibility`：`live` 为可访问链接，`planned` 显示但不可跳转，`hidden` 不参与布局。

最多十个可见入口时，宽屏使用同圆端点的环绕布局；再增加入口或进入窄屏后，改用双列索引。这个退化规则保证标题和点击区域不被挤到头像上。`archives` 入口还受现有 `features.showArchives` 配置控制。
