# 导航与返回

`data/siteNavigation.ts` 是栏目数据来源。URL 仍保持现有地址，内容层级为“首页 → Blog → 标签 / 搜索 / 归档 → 具体标签”。Blog 的可见子栏目链接与 Header 使用同一份数据并遵循搜索、归档开关；面包屑是层级导航，不承担历史返回。

文章顶部的“返回搜索结果 / 返回归档 / 返回具体标签”等入口表示回到进入该文章的站内来源，保留来源 URL 与位置，可跳过文章内部后来增加的章节锚点记录。浏览器后退则继续按浏览历史遍历，可能先退回文章内的上一章节，也可能离开本站；站点不把这项操作重定向到首页或内容父级。两者的语义不要求相同。

固定目的地使用“文章目录”或父级栏目名称，不用含糊的“返回 / Go Back”文案。没有已知站内来源时，文章入口固定为文章目录；栏目页的父级入口始终按内容层级确定。例如“文章第 2 页 → 文章 → 章节 B → 章节 C”，文章顶部的“返回文章列表”回第 2 页，浏览器后退按已有记录退到章节 B。

`PageNavigation.astro` 是 Blog 列表、详情、标签、归档、搜索及关于页共用的顶部导航。顶部只承担一个导航角色，不并列显示历史返回和层级路径：

- 栏目页在 `sm`（640px）及以上只显示可点击的祖先路径，当前页面由 H1 表明。Blog / 关于页为“首页”，标签目录 / 归档 / 搜索为“首页 / 文章”，具体标签为“首页 / 文章 / 标签”。分页不增加层级，标签原名只在标题中出现。
- 小于 `sm` 时，栏目页只显示一个带左箭头的直接父级链接，例如“文章”或“标签”。不换行、横向滚动或增加省略菜单；链接始终指向内容父级，不随浏览历史改写。
- 文章页在所有宽度只显示一个来源返回入口。来源有效时，按实际页面显示“返回搜索结果”“返回归档”或具体标签名等文案。没有来源、禁用 JavaScript 或 `showBackButton=false` 时，保留真实的“文章目录”链接；该配置只控制文章历史返回增强，不隐藏层级导航。
- 文章返回文案在容器内单行省略，完整文本仍是链接的可访问名称。来源标签通过 `data-navigation-tag` 从内容传入，存为可选 `tagName`，再用 `data-i18n-params` 插入双语模板；不从 URL 猜测原始大小写，也不翻译标签内容。

`utils/navigation.ts` 负责 base / 语言前缀剥离、祖先关系与来源文案键，供静态组件和客户端共用；不读取 DOM 或持有返回状态。路径保留编码后的内容段，语言识别只作用于部署 base 后的第一个段。

`Main.astro` 统一标题与内容的间距，`heading` 插槽容纳 Blog 子栏目入口；通用的“全部文章/标签/搜索”说明不再重复显示。页面和文章标题允许长连续技术词换行。文章详情沿用阅读排版，顶部仍由同一导航组件控制。

`navigationHistory.ts` 是页面返回来源的唯一所有者，在全站 Layout 中注册一次。Main、首页和搜索不写共享返回存储。搜索负责实时维护当前查询 URL；来源模块在站内链接点击时先捕获页面 URL 与坐标，再由路由事件作为兜底，避免准备期间的滚动或异步加载改变用户实际离开的视口位置。

- 导航到含 `data-page-navigation` 的页面时，记录切换前的完整 URL、视口坐标、可选标签原名和可用的 Astro 历史索引，写入目标条目的 `history.state["moyu:return"]`，保留路由器的其他字段。所有页面使用同一规则；刷新与前进/后退读取对应条目，不读取一个不断被覆盖的全局来源。待处理来源按目标 URL 关联，历史遍历、替换和其他页面不写入新来源。
- 来源只接受当前站点 base 内的同源 URL，包含 base 根本身，拒绝仅共享字符串前缀的其他目录。文章直达或无 JS 时回文章目录；栏目父级链接不依赖脚本。不猜测外站历史。
- 可验证的历史索引优先交由浏览器历史和 Astro 恢复位置，包括文章内增加锚点历史后的返回。来源中的 `routerIndex` 来自当前安装 Astro 的可选实现字段 `history.state.index`，只有有效且向后时使用；升级 Astro 需回归。旧版来源的 `index` 可能包含边注复制的错误索引，不用于遍历，仍可按 URL 返回。不可用时使用公开 `navigate` 替换当前条目和保存的坐标；字体完成后和执行定位帧时都核对导航版本及完整 URL，避免迟到的回调覆盖用户的新锚点或查询。
- 全局点击捕获只记录离开的 URL、位置和同页来源，不阻止普通锚点。窗口冒泡阶段在文章模块和 Astro 处理完点击后，为缺少来源的同页条目补充元数据，不新建历史条目、不覆写已有状态。点击快照以事件为 WeakMap 键；停止冒泡的事件不留下长期记录。移除锚点和重新打开相同 URL 仍可能发生文档交换，此时沿用原来源，禁止把当前页面设成自己的返回目标。
- 自定义边注通过公开 `navigate` 创建不同锚点的历史并携带状态，相同锚点的引用切换只更新当前条目。修饰键、下载、新窗口、`data-astro-reload` 和路由器的 `data-astro-history` 语义保持原状；非 HTML 链接交给原处理方。界面语言切换后重算文章返回文案，查询、锚点和标签原名保持不变。
- `navigate` 的 `info.restoreScroll` 为站内返回的定位标记；分页路由定位模块从全站 Layout 初始化，覆盖从文章刷新后首次返回分页的情况；分页遇到该标记或历史遍历时不强制滚到底部。其他目录访问也不强制到底部。

`tests/navigation.test.mjs` 覆盖部署边界、语言与编码、祖先和来源分类；`tests/navigation-history.test.mjs` 在内存转译后运行真实协调器，以 DOM / 路由边界夹具检查事件顺序、状态所有权、自引用、旧索引降级及延迟定位失效；语言回归用真实 `applyLang` 验证返回模板不会改写内容参数。夹具不代替浏览器中的实际 Astro 路由与布局验收。浏览器回归应覆盖：首页、文章/标签分页、搜索查询、文章到文章、锚点与刷新、原生前进后退、边注详情与重复引用、禁用存储、无来源和无 JS；验证 URL、内容、来源链接与位置同时正确。普通导航和分页均保留整体视图过渡，减少动态效果沿用 Astro 的退化行为。
