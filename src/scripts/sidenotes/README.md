# 边注解代码结构

入口 `../sidenotes.ts` 负责文章生命周期、布局调度、引用导航和输入事件。
模块按状态和 DOM 的归属划分：

| 文件                               | 职责                                                         |
| ---------------------------------- | ------------------------------------------------------------ |
| `model.ts`                         | 原始注解、引用关系及稳定身份、纯文本摘要；包装和还原原始内容 |
| `views.ts`                         | 预览卡片、同位置切换按钮、视图缓存和显示状态                 |
| `dialog.ts`                        | 详情框、原始内容转移、前后导航、滚动锁和关闭后的焦点恢复     |
| `motion.ts`                        | 聚焦移动、装饰影子和动画中断清理                             |
| `reading.ts`                       | 输入先后顺序、手动接管和阅读分界线记忆                       |
| `dom.ts`                           | DOM 可见性、片段 ID 解码及详情关闭事件约定                   |
| `../../utils/sidenoteGeometry.ts`  | 聚焦和预览共用的卡片完整占位范围判断                         |
| `../../utils/sidenoteSelection.ts` | 无 DOM 依赖的选中策略和分组内引用去重                        |
| `../../utils/sidenoteLayout.ts`    | 无 DOM 依赖的测量快照、连续区域划分和每帧空间判定            |

## 需要保持的约束

- `Note` 是唯一注解内容；`NoteReference` 是正文中的某一次引用。同一注解可以有多个引用位置。
- 只在同一个空间分组中合并重复内容，避免远处的重复引用失去自己的导航位置；保留精确的引用目标。
- 视图缓存、分组选择记忆和动画通过 `referenceKey` 使用原始引用 DOM 的身份；无引用时使用注解源节点。不要用临时分组对象或各自拼接的字符串替代，避免重排后缓存与动画对不上。
- 卡片的自然占位相互重叠或间距不足时组成连续区域，视窗外的注解也参与划分。稀疏注解是单点区域；`baseStatic` 只表示有空间显示的单点区域，与是否聚焦无关。
- 每个连续区域选择一条代表：焦点在区域上方时取上端，在下方时取下端；焦点进入区域后由当前聚焦注解代表它。候选范围限制在带缓冲的视窗内；代表与聚焦冲突时优先保证聚焦可读。
- 常显示预览的判定范围向实际视窗上下各扩展 `6rem`，按卡片完整占位相交判断，不能只检查引用点。定位与缓冲区不截到正文末尾，避免最后一张卡片尚在屏内就因可用高度收缩而隐藏；轨道仍限于正文高度。
- 自动聚焦使用阅读区自上而下 40% 处的不可见分界线：向下滚选择刚越过线的引用，向上滚反向推进；无新引用越线时保留选择。尺寸或内容变化重新定位分界线，不视作滚动。
- 新的鼠标或键盘选择优先。继续滚动时，若选择仍在阅读方向前方则保留，直到阅读进度追上；若选择已落在分界线后方，则恢复自动聚焦。静止的鼠标不会反复覆盖阅读进度。
- 同一帧内按输入实际发生的先后顺序接管；几何重测只重设阅读基线，仍在范围内的选择保持不变。
- `baseStatic` 表示该卡片是否属于常显示类型；聚焦是独立状态，不改变这个分类。
- 卡片位置只由正文锚点与测量高度决定，常显示、区域代表及聚焦共用自然位置；视窗只参与显隐判断，不独立夹紧卡片。否则滚动经过边缘时原本有空隙的卡片会被挤在一起，造成隐藏后重现。靠近上下边缘的卡片随正文自然进出，完整内容可通过详情查看；鼠标接管只影响选中优先级。
- 两侧轨道统一使用低对比度中性色，避免暗色主题的橙色边框变量使整条轨道过重。每侧留白按 `(可视宽度 − 正文宽度) / 2` 计算：15% 用作正文到轨道的间距，侧栏宽度取留白的 75% 与 `20rem` 中较小者，其余留在屏幕边缘。比例及宽度上限统一定义在 `global.css` 的 `--article-side-*`，左栏读取同一配置，目录不存在时也保持布局。左栏宽度包含轨道内缩的 `0.5rem`；不足 `12rem` 时保留窄屏退化。编号仅轻微强调，普通连接线和卡片使用较低对比度。
- 所有实际显示的卡片均连接到对应分组节点，普通预览使用中性色、焦点使用强调色；隐藏卡片及动画影子不额外画线，避免密集区域出现无目标连线。普通线共用一条 SVG 多段路径，滚动时不逐条创建 DOM。
- 同一密集区域内聚焦切换只移动；跨区域切换或涉及单点常显示注解时使用装饰影子，让聚焦卡片与区域代表衔接。
- 快速切换打断动画时取消旧影子并跳过本次新影子，避免拖出残影；真实聚焦立即更新，不等待动画。
- 预览使用纯文本，富内容及其 ID 不复制；详情框关闭时将原始节点放回文末。
- 布局阶段集中测量高度并缓存自然位置和区域划分，滚动绘制阶段只更新显隐和区域代表；同位置按钮保持 DOM 身份以保留键盘焦点。

## 计算边界

`reading.ts` 独占输入来源、滚动方向和上次分界线的记忆；纯选中策略只接收快照，
不操作 DOM 或修改分组。入口仍持有精确的引用选择，区域索引不作为跨布局的持久身份。

`prepareSidenoteLayout` 接收按锚点升序排列的高度测量及间距，复制为独立几何快照。
返回的计算器只接收每帧的视窗与聚焦参数；引用位置、高度、字体或间距变化时必须重建。
所有纵坐标均相对文章顶部；索引为 `-1` 表示无选择。`baseStatic` 表示可单独常显的稀疏注解，
`visibleRepresentative` 表示密集连续区域当前选出的预览。聚焦状态由入口单独组合，不能混入空间分类。

## 生命周期

入口持有事件的 `AbortController`、观察器和动画帧。页面切换时先关闭详情，
再中止监听、取消帧和动画、断开观察器，最后移除预览并还原原始注解。
各模块只清理自己创建或临时修改的资源。

详情模块在转移正文或释放滚动锁前发送 `sidenote:before-close` 冒泡事件。
文章页的内联图片查看器监听同名事件，先关闭嵌套图片，再由详情模块恢复页面滚动。
