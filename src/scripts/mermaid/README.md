# Mermaid 阅读交互

入口为 `../mermaid.ts`，聚焦视图由 `focus.ts` 管理，样式位于 `../../styles/mermaid.css`。工程规范入口见 `../../../docs/engineering/README.md`。

## 源码、状态与生命周期

- 只增强明确的 `pre[data-language="mermaid"] > code` 或 `pre > code.language-mermaid`。`astro.config.ts` 将 Mermaid 排除在 Shiki 高亮之外，保留围栏标记和源码；不按内容关键词猜测普通代码。
- 每个围栏持有不可变的 `code.textContent`、原始 `pre`、独立的图表/源码选择和 loading/ready/error 状态。源码不从 SVG 反推，也不通过 `innerHTML` 插入。成功默认显示图表；首次等待和失败时保留源码，并显示双语状态。切换主题不覆盖读者的源码选择，已有图形在新渲染结果完成前保持可见。
- 文章代码增强模块跳过这些围栏，避免第二套复制按钮和包装层。源码可以直接选择、复制，代码换行保留；无 JavaScript 时仍是静态代码块。
- Mermaid 与媒体预览样式由 `PostLayout.astro` 静态导入，确保 Astro 客户端路由首次展示增强后的 DOM 前，样式表已进入文章页面。客户端交互模块只负责行为，不承担 CSS 注入，避免首次增强 DOM 时控件暂时显示成未样式化状态。
- Mermaid 配置由入口独占。全模块串行队列包围 `initialize` 和 `render`，每轮捕获主题、页面版本；每次 await 后复核版本，旧结果不能回写。根 `data-theme` 变化按帧合并后触发主题相关图的重渲染；固定配色图复用已有 SVG。源码视图选择不受主题变化影响，语言变化只更新 UI，不改变源码。
- 测量容器由入口创建、登记并在 finally 删除；`astro:before-swap` 同步取消页面资源、移除测量 DOM、还原原始 `pre`。已开始的第三方 Promise 无法取消，但完成后不能写入新页面；下一页渲染继续使用同一串行队列。`astro:page-load` 可重复调用，不重复创建控件。
- 源码复制在剪贴板 Promise 成功/失败后检查页面仍有效。每张图只保留一个复制反馈计时器，重复复制替换旧计时器，页面离开时取消；已经结束的页面不再新建反馈资源。

## 配色策略与限制

默认图使用 Mermaid 的 default/dark 主题，承载面对应浅色/本站深色。检测到 `classDef`、`style`、`linkStyle`、常见 fill/stroke/color 声明、配置指令或 frontmatter 时，保守地使用 default 主题和白色承载面，保留作者配色。配置检测允许误判为浅色图，例如只设置标题的 frontmatter；这比自动猜测任意作者色盘更稳定。

文章排版会给 `p`、`strong`、`code` 等元素指定页面前景色，这会污染 Mermaid 的 HTML 标签。功能样式仅让 SVG foreignObject 中这些元素重新继承 Mermaid/作者定义的文字色，不重写节点填充、描边或所有节点文字颜色。红蓝图使用原始 `#fee2e2` / `#dbeafe` 填充、深红/深蓝文字，连线、箭头、子图和标签沿用浅色 Mermaid 配色。

这不是任意作者色盘的自动对比度修复：白字透明底、低对比显式颜色、外部 CSS 色盘、复杂自定义主题仍需作者自行保证可读。配置指令可能进一步改变图表配色。渲染使用 Mermaid strict 安全级别，不启用作者 JavaScript 回调；复杂 HTML 标签遵循 Mermaid 的净化规则。

## 聚焦与覆盖层契约

- `createMermaidFocus()` 管理一个原生 modal dialog、副本尺寸适配、ResizeObserver、开启前焦点和自身的滚动锁释放句柄；缩放状态归共享手势模块、滚动样式快照归共享滚动锁模块。没有跨页缩放持久化。
- 每次打开都传入当前图的 `isPending` 只读回调。入口仍独占每图 phase，状态更新时调用 `refreshState(target)`；聚焦模块仅刷新当前目标，关闭时释放回调。没有跨会话保存的 pending 布尔值，旧渲染或其他图的完成不能改变当前弹层的忙碌状态。
- 点击“放大图表”或键盘激活按钮进入；图表本身也可点击、聚焦后按 Enter/空格打开。界面使用右上悬浮图标开关切换源码和图表，内容与图标即时硬切。聚焦视图提供与文章图片预览相同的控件、手势、快捷键、遮罩点击关闭及 4 倍缩放上限：滚轮/触摸缩放、拖动平移，双击/双击触摸放大或复位，`+`/`-` 缩放、`0` 适应视口、方向键平移。
- 正文拥有当前有效 SVG，聚焦不移动原图；dialog 使用一份副本，给副本内 ID 加独立前缀，并同步改写 `url(#...)`、片段链接、ARIA ID 引用和 SVG 内样式选择器，避免与正文副本冲突。关闭时无需恢复或补占位。主题渲染成功后，入口先更新正文 SVG，再显式刷新当前聚焦副本；不通过另一个 DOM 观察器重复克隆。等待期间保持已有图形及缩放控件可见，仅标记 `aria-busy` 和显示状态提示；只有首次打开尚未准备好副本时隐藏画布。保留当前缩放比例，失败时回退源码并显示状态。
- 原生 top layer 负责遮挡和背景 inert，显式 Tab/Shift+Tab 首尾循环；Escape 或关闭按钮返回触发控件。入口显式传入备用视图切换按钮，触发控件禁用、隐藏或脱离文档时返回该按钮；不依赖工具栏兄弟顺序。渲染失败则返回已经显示的源码块。页面离开不抢回旧页面焦点。弹层标记 `data-reading-focus-ignore`，不受正文阅读聚焦覆盖层影响；打开、关闭和缩放控件带短过渡，尊重减少动态效果设置。
- 图表聚焦与图片预览调用同一套交互模块，保持一致的关闭、遮罩、Escape、焦点返回、缩放与平移行为。已有图片预览打开时不再叠加 Mermaid；模态开启后背景图片不可交互。边注解之上可开启原生 Mermaid dialog，`sidenote:before-close` 先关闭内层，再由注解释放外层锁。
- 共享手势事件只更新最新 scale/x/y 并调度一个动画帧，帧内统一读取尺寸和绘制。新手势开始、结束或尺寸刷新时同步提交必要的最终位置；销毁时取消待执行帧。两种预览的内部关闭函数均使用 `close({ immediate, restoreFocus })`，默认保留各自关闭效果并恢复焦点，离页则立即关闭且不抢回焦点。
- 遵循全局布局契约：根 `html` 的 `scrollbar-gutter: stable` 由全局 CSS 从首次绘制预留；通过 `acquirePageScrollLock()` 锁定根滚动，并在锁期间把稳定 gutter 转移到 body 内容盒。锁支持嵌套，关闭时释放本模块持有的句柄；不要自行保存/恢复根或 body 的滚动样式。
