# 文章列表分页

[`Pagination.astro`](../../components/Pagination.astro) 呈现静态导航，`index.ts` 管理展开/关闭，Layout 中的 `position.ts` 管理全站生命周期的路由定位，`reel.ts` 独占拖拽、滚轮、键盘输入与资源清理，路径和旧地址兼容位于 [`utils/pagination.ts`](../../utils/pagination.ts)。

- `posts.perPage` 控制文章及标签列表，默认 8；首页 `perIndex` 独立。末页按实际剩余文章显示。
- 常驻分页仅保留上一页箭头、当前页/总页数和下一页箭头。计数不显示上下展开指示符，点击仍可展开/折叠所有页码；不常驻显示文章范围统计、额外页码条或输入表单。箭头和计数名称接入双语，数字不参与翻译。
- 原生 `details/summary` 和真实页码链接保证无 JavaScript 仍可展开、翻页。页码为单行横向卷轴，每项固定 44×44px，少量页码按内容收窄，较多时受视口与 30rem 上限约束。仅上下两条两端渐隐的分割线，页码在左右边缘渐隐，不显示左右边框、外框阴影或滚动条。背景使用主题色的 20% 不透明度与局部 2px 轻模糊，需能透出叠在下面的正文笔画；不能用近乎不透明底色或强模糊遮住正文。保留原生触摸/触控板滚动与吸附；鼠标左键移动超过 5px 后捕获指针并拖拽，拖动期间关闭吸附，释放后恢复，拦截拖动产生的点击以免误跳页。
- 有横向溢出时，将页码区域内的纵向滚轮映射为横向滚动；横向触控板交由浏览器处理，Ctrl/Meta 滚轮保留原行为，无溢出时不拦截页面滚动。滚轮增量按帧合并，支持 pixel/line/page 单位。滚动期间暂停吸附，140ms 无新输入后恢复，避免小幅输入被逐次吸附吞掉。ResizeObserver 缓存尺寸，避免高频滚轮回调读取布局。
- 客户端展开后居中并聚焦当前页，左右键和 Home/End 移动焦点，Escape 关闭并返回触发控件，外部点击/焦点离开时关闭；元素断开时取消监听器、尺寸观察器、指针捕获、滚轮结束计时器与待执行帧。菜单使用站点 popover 层级和主题颜色。
- 分页占据列表与页脚间的底部位置：短列表由分页的自动上边距消化留白，有分页时页脚不再设置自动上边距。页码条绝对定位向上展开，不撑高文档；所有分页链接携带 `#pagination`。原生锚点支持无 JS；全站 `position.ts` 只在明确抵达分页锚点时，于字体布局稳定后修正到文档底部。普通目录访问不强制滚到底部；历史前进/后退及带 `restoreScroll` 标记的站内返回交由 Astro 保留来源位置。
- 分页控件通过局部 `scroll-behavior: auto` 避免展开定位产生平滑滚动。分页导航保留 Astro 根页面视图过渡；卡片标题不单独做共享元素移动，避免标题和摘要以不同节奏错位。文章与标签列表使用相同分页定位和返回规则。
- 主题模块在切换前将有效的 `data-theme`、dark class 与 theme-color 写入新文档，避免根属性短暂丢失触发多余颜色过渡；分页模块不另行维护主题状态。
- 文章与标签列表随根快照整体过渡，传给 `Card` 的 `transitionTitle={false}` 真正不输出卡片标题的过渡指令，保证其他列表导航时标题、日期、标签与摘要同步；`transition:name={undefined}` 会被 Astro 生成为自动名称，不能用于关闭。其他 `Card` 调用默认保留标题过渡。
- 文章与标签目录共用顶部 `PageNavigation`，面包屑和返回遵循[导航规则](../navigation.md)；省去重复的通用说明。`Main` 未收到说明时不输出空段落，Blog 子栏目入口放入其 `heading` 插槽。卡片标题和摘要允许长技术词换行，日期/标签与摘要用间距分层，不截断文章内容。
- 第一页路径来自 Astro `page.url.first ?? page.url.current`，后续页保留部署 base、语言和标签路径，第一页不添加 `/1/`；前后箭头、展开页码与兼容跳转统一使用尾斜杠。
- 从原每页 4 篇迁移时，只有新页不存在的旧路径生成静态跳转到当前末页；未来真实页面优先。中文目标经 URL 编码满足 Location 约束；GitHub Pages 使用生成的 meta refresh。文章详情 URL 不变。

后续维护需覆盖：真实多页的拖拽/滚轮/触摸、RTL 居中、关闭时取消待执行输入帧、快速离页、历史位置恢复与无 JS 导航。
