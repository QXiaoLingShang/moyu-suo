# 阅读聚焦

文章信息下方的「阅读聚焦」菜单提供鼠标跟随开关、左侧线 / 右侧线 / 区域高亮三种样式，以及独立的目录标题提示开关。颜色跟随当前主题的强调色。读者也可调整标题高亮时长（2–8 秒）和跳转顶部留白（视口高度的 10%–40%）。

## 站点配置

`astro-paper.config.ts` 的 `features.readingFocus`：

| 配置                   | 默认值   | 作用                                                         |
| ---------------------- | -------- | ------------------------------------------------------------ |
| `enabled`              | `true`   | 是否提供菜单和聚焦功能；关闭后已保存的读者偏好也不会启用功能 |
| `defaultEnabled`       | `true`   | 首次访问时是否跟随鼠标                                       |
| `defaultStyle`         | `"left"` | 首次访问的样式：`"left"`、`"right"`、`"block"`               |
| `highlightTocTarget`   | `true`   | 首次访问时是否提示目录跳转标题                               |
| `highlightDuration`    | `4000`   | 标题高亮时长，毫秒；限定在 2000–8000，并按整秒取整           |
| `headingOffsetPercent` | `22`     | 跳转时标题上方保留的视口高度百分比；限定在 10–40             |

读者选择优先于默认值，存储在当前站点的 `localStorage["moyu-reading-focus:v1"]`。
存储不可用时，选择在当前页面和 Astro 页面切换期间仍然有效。损坏或不支持的设置回退到站点默认值。

## 状态规则

- `preferences.ts` 读写偏好；`index.ts` 协调页面生命周期与共享偏好；`controls.ts` 管理菜单事件和控件显示；`pointer-focus.ts` 管理鼠标/键盘命中和覆盖层；`regions.ts` 解析阅读块；`target-highlight.ts` 管理标题提示计时。样式位于 `src/styles/reading-focus.css`。
- 菜单在窄屏也可用，支持键盘 Tab、原生单选框方向键与 Escape 关闭。禁用 JavaScript 时隐藏菜单，正文保持静态 HTML。
- 鼠标跟随只响应支持悬停的鼠标事件，触摸不会点亮区域；正文链接和代码块得到可见键盘焦点时也可显示聚焦提示。
- 右侧目录、正文目录和标题自身的同页锚点均可触发标题提示。保留原生锚点、地址和历史记录行为，用 `scroll-margin-block-start` 提供顶部留白，默认 22vh。关闭高亮也保留阅读留白；无 JavaScript 时使用 22vh。页面首尾的落点受浏览器可滚动范围约束。
- 点击后立即显示标题底色，滚动期间保持高亮，到位后再开始计算设定时长（默认 4 秒），结束前才淡出。重复点击会重新计时，快速切换目标、关闭开关和页面切换都会清理旧提示。带修饰键的新窗口操作不触发当前页面提示。
- 鼠标或键盘切换阅读块时，强调线和高亮矩形以 200ms 平滑移动并调整尺寸。首次进入直接定位；滚动和布局变化时只更新位移与尺寸，避免拖尾，并用变换绘制移动以减少重排。
- 鼠标移动、滚动和窗口变化通过 `requestAnimationFrame` 合并命中检测、布局读取与覆盖层更新；图片/公式等引起的正文尺寸变化也会更新。Astro 页面切换时移除监听器、观察器、计时器和覆盖层。
- 减少动态效果偏好下不做平滑滚动、淡入淡出；标题显示短暂的静态底色。打印时不显示菜单、覆盖层或标题提示。

## 可聚焦内容

文章主标题、正文标题、段落、列表项、代码块、引用、表格、图片、公式、图表、折叠摘要、分隔线、文末注解和 callout
视为阅读块。嵌套内容优先选取鼠标命中的最近文本块，代码块、表格、图片容器与公式保持整体。正文块间 24px 内的小空白选择最近的内容；左右强调线始终对齐正文边缘，避免在缩进内容间跳动。超长块只绘制视口内可见范围，覆盖层不接收点击，不改变正文布局。

动态生成的边注解和详情弹层不参与聚焦，避免与旁注自身的预览交互竞争。特殊交互区域可加 `data-reading-focus-ignore` 排除。
