# 架构与接口

## 目录职责

| 位置 | 主要职责 |
| --- | --- |
| `src/pages/` | Astro 路由、取数和页面组合；避免复制组件内部的交互逻辑 |
| `src/layouts/` | 页面共享结构、元数据和全局脚本入口 |
| `src/components/` | 可复用的页面片段和呈现；复杂交互委托给脚本模块 |
| `src/data/` | 导航、首页入口等可维护的静态站点数据 |
| `src/content/` | Astro 内容集合中的页面内容；内容字段约定由内容 schema 管理 |
| `src/i18n/` | 文案字典、类型和运行时语言切换 |
| `src/scripts/` | 浏览器交互、DOM 生命周期和功能协调 |
| `src/types/` | 跨模块共享的配置和领域类型 |
| `src/utils/` | 可复用计算、格式化和路径辅助逻辑；不拥有页面交互状态 |
| `src/styles/` | 全局 token、共享排版和页面/功能样式 |
| `posts/` | Markdown 文章源和写作约定 |
| `public/` | 按原路径复制到站点输出的静态文件 |

页面组合组件和数据；组件呈现语义化 HTML；脚本增强交互；工具模块提供可复用逻辑；样式消费 HTML 的类名和状态属性。避免循环依赖和跨层直接操纵内部状态。

## 状态所有权

- 每份可变状态有明确所有者。需要协作时，通过参数、返回值、回调或明确的 DOM 事件传递，不让多个模块同时写同一状态。
- 页面生命周期协调器负责初始化和清理；功能模块只清理自己创建的监听器、观察器、动画、计时器和临时 DOM。
- 纯计算接收显式输入并返回结果；不要从纯计算模块读取或修改 DOM、`localStorage` 或全局交互状态。
- 复杂交互先按职责和状态归属拆分。保留简单入口作为协调器，不让入口重复实现子模块算法。

## 模块接口

- 导出的函数只暴露调用方需要的输入、结果和清理方式；内部 DOM 与临时状态保持私有。
- 多个相关参数或含义相近的参数使用具名 options 对象，避免依赖位置猜测调用含义。
- 组件/脚本间的回调应表达明确事件或意图；不要让调用方直接修改另一个模块的内部对象。
- 跨模块 DOM 属性、事件名、存储键和配置字段都是接口。更改时搜索所有写入方、读取方、清理方和样式消费者，并同步局部文档。
- 配置的名称、类型、默认值、运行时行为和说明保持一致；共享来源可派生的值不要重复维护。

## 拆分判断

当模块同时承担多个独立变化的职责、持有不属于它的状态，或无法独立理解其接口时再拆分。不要只为缩短文件而增加转发层、万能工具模块或抽象工厂。
